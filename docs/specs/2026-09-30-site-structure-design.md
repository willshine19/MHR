# 站点结构与第一页设计

日期：2026-09-30

## 定位

给用户本人看的《怪物猎人 崛起：曙光》Switch 版定制攻略。主武器长枪，当前进度大师级 2★。内容打到哪写到哪，不预先铺满所有栏目。

内容准确性、译名、信息源规则以 `CLAUDE.md` 为准，本文不重复。

## 目录结构

```
MHR/
├── CLAUDE.md
├── docs/specs/                  # 设计文档，不发布
├── site/                        # 发布到 GitHub Pages 的全部内容
│   ├── index.html               # 首页
│   ├── builds/mr2.html          # 第一页：长枪技能优先级 + MR 2★ 配装
│   ├── about.html               # 版本基准、资料来源、译名说明
│   └── assets/css/site.css      # 全站共用样式
└── .github/workflows/pages.yml  # 用 GitHub Actions 只发布 site/
```

以后按需新增，现在不建：

- `lance/`：长枪操作、招式、替换技。技能优先级需要跨多个进度共用时，从 `builds/mr2.html` 拆到这里。
- `monsters/<英文 slug>.html`：长枪视角的怪物笔记。
- `builds/mr<N>.html`：其他进度的配装。

## 页面约定

- 文件名和目录用英文小写 kebab-case；页面内容用游戏内简体中文官方译名。
- 站内链接和资源一律用相对路径。
- 每个内容页的标题下方有一行元信息：适用进度 · 数据版本 · 核对日期，例如「MR 2★ · Ver.16.0.2（Kiranico v16.0.0）· 2026-09-30 核对」。
- 每个内容页底部有「资料来源」列表，链接到实际引用的页面。
- 每页顶部都有相同的手写导航：首页 / 配装 / 关于。
- 纯 HTML + 一个共用 CSS，不用 JS、不用构建工具。

## 样式

- 以手机为主：正文宽度上限约 720px 居中，两侧留 16px 边距，页面不出现横向滚动；宽表格放进可以横向滚动的容器里。
- 颜色用 `:root` 上定义的 CSS 变量，通过 `prefers-color-scheme: dark` 提供深色模式；`body` 设置明确的背景色。
- 字体用系统中文字体栈，不加载外部字体。

## 第一页：`builds/mr2.html`

1. **技能优先级**（长枪通用）：防御性能 5、攻击守势 3（长枪核心）→ 攻击 ≥4、弱点特效 3（输出）→ 超会心 / 看破 → 翔虫使、防御强化（辅助）。每项写目标等级和理由，效果数值取自 Kiranico 的技能说明。
2. **MR 2★ 配装：土砂龙X 全套**：逐个部位的技能与孔位表，以及套装合计（防御性能 5、攻击守势 3、攻击 5、防御 5）；注明土砂龙在 MR 1★ 任务「满身的泥泞就是王牌」中登场。
3. **装饰品方案**：痛击珠【2】×3 + 攻击珠【2】×2 放 ④④③②② 孔；耐绝珠【1】或防御珠【1】放 ①①① 孔；武器孔放超心珠【2】、达人珠【2】或翔虫珠【2】。合计效果：攻击 7、弱点特效 3、防御性能 5、攻击守势 3。
4. **注意事项**：Lv4 珠子需要怪异原珠或明王原珠，MR 2★ 做不了；2 级珠子能不能做以游戏里加工屋的显示为准，缺痛击珠时用挑战珠【2】或达人珠【2】替代。
5. **武器参考**：远古巴别塔・改、飞雷枪【御手杵】改、骨爪长枪，写明攻击、属性和孔位。
6. **资料来源**：GameWith、Game8、Kiranico 的对应页面。

## 发布

`.github/workflows/pages.yml` 在推送到 `main` 时，把 `site/` 目录作为 Pages 产物上传并部署。仓库目前还没有 GitHub remote，用户建好仓库、把 Pages 的来源设为「GitHub Actions」后才能生效。

## 验证

- 用 `python3 -m http.server -d site` 在本地预览，逐页打开检查。
- 在 375px 宽度和深色模式下检查：没有横向滚动，表格可以横向滚动，文字清晰可读。
- 所有站内链接都能打开，没有以 `/` 开头的绝对路径。
- 页面上的名称和数值与 Kiranico 一致。

## 不做

搜索、JS 交互、构建工具、`lance/` 和 `monsters/` 目录、其他进度的配装。
